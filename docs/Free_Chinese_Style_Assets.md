## 💡 素材改编建议

如果找不到完全符合三国志11风格的素材，可以这样改编：

1. **色彩调整**
   - 使用三国志11色调（参考配色表）
   - 降低饱和度，增加古典感
   - 添加水墨效果的滤镜

2. **元素叠加**
   - 基础地形 + 中国元素（如竹林、古树）
   - 使用图层叠加增加细节

3. **风格统一**
   - 所有素材使用相同的滤镜
   - 统一边缘处理方式
   - 保持色调一致性

## 🎯 快速获取流程

### Step 1: 浏览资源网站
推荐顺序：
1. OpenGameArt.org（搜索 `chinese tileset`）
2. Kenney.nl（查看基础地形）
3. itch.io（搜索 `chinese game assets`）

### Step 2: 下载素材
- 确认版权许可
- 下载PNG/BMP格式
- 检查分辨率是否符合需求

### Step 3: 整理素材
保存到项目目录：
```
/home/chang/TowerDefense/assets/
├── terrains/        # 地形素材
├── buildings/       # 建筑素材
└── nature/          # 自然元素
```

### Step 4: 后期处理（可选）
- 调整色彩匹配三国志11风格
- 缩放到256x256像素
- 测试平铺效果
