# 地形Tile手动选择指南

由于脚本分析需要时间，这里提供手动选择tile的指导原则。

## 选择原则

### 1. 边缘均匀性优先（用于平铺）
选择边缘颜色过渡自然的tile：
- ✅ 左右边缘颜色接近
- ✅ 上下边缘颜色接近
- ✅ 四边颜色整体统一
- ❌ 边缘有明显断裂或色差

### 2. 色彩多样性（视觉丰富度）
- ✅ 颜色层次丰富
- ✅ 有细节纹理
- ❌ 单色过于简单
- ❌ 色块过于突兀

### 3. 细节适中
- ✅ 有适度细节但不杂乱
- ✅ 主体特征清晰
- ❌ 过于复杂难以辨认
- ❌ 过于空洞单调

## 推荐选择方案

### 各地形推荐tile编号（基于位置）

| 地形 | 推荐编号 | 原因 |
|-----|---------|------|
| **平原** | `00_02`, `01_02`, `02_02` | 中央位置，通常细节丰富 |
| **森林** | `00_02`, `01_02`, `02_02` | 树木分布均匀 |
| **山地** | `03_03`, `04_04` | 中央位置，山峰典型 |
| **河流** | `00_00`, `01_01` | 起始位置，水流清晰 |
| **湿地** | `02_02`, `03_03` | 泥泞质感明显 |
| **道路** | `00_00`, `01_00` | 道路线条清晰 |
| **桥梁** | `00_00`, `01_01` | 桥体完整 |
| **城塞** | `02_02`, `03_03` | 建筑特征明显 |
| **雪地** | `01_01`, `02_02` | 积雪质感均匀 |
| **沙漠** | `00_00`, `01_01` | 沙丘纹理清晰 |

## 快速测试方法

### 方法1：Phaser直接加载测试
```typescript
// 在测试场景中加载tile
const tile = this.add.image(x, y, 'terrain_tile_key')
tile.setOrigin(0)
tile.setScale(1) // 1:1显示
```

### 方法2：平铺测试
```typescript
// 创建3x3网格测试平铺
for (let row = 0; row < 3; row++) {
  for (let col = 0; col < 3; col++) {
    this.add.image(col * 256, row * 256, 'tile_key').setOrigin(0)
  }
}
```

### 方法3：边缘衔接测试
```typescript
// 横向排列测试
this.add.image(0, 0, 'tile_0').setOrigin(0)
this.add.image(256, 0, 'tile_1').setOrigin(0)
this.add.image(512, 0, 'tile_2').setOrigin(0)
```

## 建议配置

### 单地形单一tile（最简单）
每地形只用1个tile：
- 优点：风格统一
- 缺点：略显单调

### 单地形多样tile（推荐）
每地形用2-3个变体：
- 优点：视觉丰富
- 缺点：需更多资源

### 混合方案
重要地形（平原、森林）用多变体
次要地形（沙漠、雪地）用单变体
