# 三国五行塔防 (Three Kingdoms Five Elements TD)

基于 **Phaser 3 + TypeScript + Vite** 构建的水墨国风、肉鸽（Roguelite）五行连锁塔防游戏。

---

## 🌟 核心设计理念（局外保下限、局内定上限）

本项目致力于解决传统塔防游戏“固定阵容+纯数值养成导致关卡套路化、后期枯燥刷图”的痛点，严格遵循**《五行塔防第一性原理》**（详见 `docs/Wuxing_System_Design.md`），杜绝数值恶性膨胀：

### 1. 严格四独立伤害乘区与抗性保底铁律
* **严格四乘区计算公式（严禁私设独立乘区）**：
  $$\text{最终伤害} = \text{基础基数} \times (1 + \sum \text{攻击力加成}) \times (1 + \sum \text{增伤加成}) \times (1 + \sum \text{易伤加成}) \times (1 + \text{实际暴伤倍率})$$
  * **区内加算、区间乘算**：相生倍率、天时红利、阵脉连线归入【增伤区】；破壁破甲、状态层数归入【易伤区】。
* **局外数值天花板（保底限）**：武将等级、星级、神兵面板、宝石属性累加基础攻击力与基础面板**总增益上限 $\le +50\%$**，杜绝局外数值碾压。
* **敌军抗性下限保底**：敌军【防御】、【韧性】与【刚毅】削减无论通过何种 Debuff 累加，最终生效值**不得低于初始值的 $40\%$**，Boss 绝不沦为木桩肉鸡。

### 2. 敌我五大属性与五行基础状态（一对一克制边界）
* **我方五维属性**：`攻击力 (attack)`、`攻击范围 (range)`、`攻击速度 (attackSpeed)`、`暴击几率 (critRate)`、`暴击伤害 (critDamage)`。
* **敌军五维属性**：`生命 (hp)`、`防御 (defense)`、`移动速度 (moveSpeed)`、`韧性 (tenacity — 反暴击率)`、`刚毅 (fortitude — 反暴击伤害)`。
* **五行五大基础状态（附着 2.5s，克制 Debuff 全程在线）**：
  * 🌿 **【木·毒】(`parasite`) $\to$ 专克【生命】**：按最大生命值百分比持续腐蚀 + 禁疗压制；
  * 🗡️ **【金·裂】(`bleed`) $\to$ 专克【防御】**：**唯一破甲基础状态** + 随敌军移动触发的无视防御流血真伤；
  * 💧 **【水·湿】(`wet`) $\to$ 专克【移速】**：**唯一移速削减软控**（基础状态不含冰冻硬控）；
  * ⛰️ **【土·重】(`heavy`) $\to$ 专克【韧性 & 刚毅】**：大幅削减敌军反暴击率与反暴伤，受暴击触发【负重内震】（不减速、不破甲）；
  * 🔥 **【火·灼】(`burn`) $\to$ 放大【攻击力】**：高频攻击力百分比火伤 DoT + 阵亡余烬爆燃传染。

### 3. 五行相生化学连锁与 160px 相生阵脉
* **双向无序触发 & 1.5s ICD 相生不抹除底层状态**：
  1. 💧生🌿 **水生木【滋养·蔓延】(`nourish`)**：软控升级为 **2.0s 藤蔓定身硬控**，并向周围扩散【木·毒】；
  2. 🌿生🔥 **木生火【燎原·焚尽】(`wildfire`)**：引爆【木·毒】造成最大生命百分比巨额爆发 + 范围火海挂【火·灼】；
  3. 🔥生⛰️ **火生土【熔岩·焦土】(`magma`)**：引爆生成 4.0s 熔岩焦土，持续灼烧并削减敌军【韧性】与【刚毅】；
  4. ⛰️生🗡️ **土生金【淬刃·锋芒】(`spikes`)**：享“土破韧刚、金破护甲”双重红利，迸射 3 道高暴伤淬刃剑气并即时结算流血真伤；
  5. 🗡️生💧 **金生水【寒芒·碎冰】(`shatter`)**：寒水顺护甲裂隙灌入，造成无视防御破冰伤害并触发 **2.5s 绝对冰封**。
* **相生共鸣取优法则**：相生基础伤害始终取双将中攻击力最高者为主基数，并附加搭档 $25\%$ 攻击力加成。
* **160px 水墨相生阵脉**：两名相生武将距离 $\le 160\text{px}$ 生成地面阵脉连线，优先锁定搭档触发相生，交叠区元素衰减减缓 $30\%$，相生伤害与破盾效率提升 $+35\%$。

### 4. 武将养成、专属神兵与宝石工坊
* **五虎上将开局全解锁**：关羽（木）、黄忠（金）、张飞（土）、马超（火）、赵云（水），支持 5 人齐上阵。
* **北斗命盘（1★~5★）**：1★ 初始平权，2★ 开同源槽，3★ 觉醒本命特质，4★ 开相生槽，5★ 觉醒五行圣兽终极大招。
* **专属神兵与双槽三才共鸣**：击败 5 大关底统帅必掉宿命主材，蒲元铸剑坊一生仅需铸造 1 把。佩戴专属神兵战法质变；嵌同源宝石与相生宝石触发双槽特效。
* **五行灵石工坊**：每颗灵石 2 条随机基础属性，三才炼石炉三合一升阶时指定主石 100% 继承词条类型。

### 5. 15 波紧凑战役与 Boss【五行铁壁】破盾
* **单局 15 波战役（10~12 分钟）**：经历 3 个动态天时周期（Wave 1~5 开局天时与先锋统帅、Wave 6~10 次席天时与中军统帅、Wave 11~15 晴空朗日守关主帅决战）。
* **三国五大统帅 Boss**：吕布、曹操、周瑜、孙权、司马懿。拥有 3~5 格相生铁壁，任意相生削减 1 格，命脉弱点相生削减 2 格并瘫痪易伤 3s。
* **局内 5 次锦囊自选**：Wave 1 开局、Wave 4/7/10/13 清波后各抽 1 次三选一，保底契合卡与 2 枚易策令。
* **凯旋班师 vs 乘胜北伐**：第 15 波通关后自主抉择：凯旋领奖或无缝踏入 Wave 16+ 无尽烽火。

### 6. 水墨宣纸国风美学与高清晰度排版
* **零外置素材纯矢量水墨**：严格遵循《芥子园画谱》式的宣纸墨韵，WebAudio API 现场物理合成古风音效（`SoundFX.ts`）。
* **高清晰度文字排版引擎**：
  * 全平台楷体栈（`INK_FONT`）与整数像素对齐；
  * 高分屏动态超采样（DPI 保底 2x，$\le 14\text{px}$ 保底 3x）；
  * 调色板全面升级高对比度焦墨深褐（`#484236`，对比度 $\ge 6.2:1$），彻底消除文字发虚发灰；
  * 小字号默认字重加固（`bold: true`），汉字笔画清晰饱满。

## 🛠️ 技术栈与架构

* **游戏引擎**：Phaser 3.70+
* **开发语言**：TypeScript 5.3+
* **构建工具**：Vite 5.0+
* **单元测试**：Vitest 1.0+（全量 16 个套件，120 项单元测试 100% 通过）
* **核心目录**：
  ```
  src/
  ├── config/          # 游戏、五行、网格与天时配置
  ├── core/
  │   ├── augment/     # 军师锦囊能量、抽取与机制改写
  │   ├── battle/      # 核心战斗控制器、四乘区伤害计算、天时系统
  │   ├── elemental/   # 五行元素状态与相生反应管理器 (ElementalReactionManager)
  │   ├── enemy/       # 敌军生成、移动与 Boss 五行铁壁
  │   ├── hero/        # 武将管理、北斗命盘、战法进化
  │   └── level/       # 战役关卡波次与无尽模式 (EndlessModeManager)
  ├── data/            # 关卡、武将、神兵、敌军与锦囊池配置数据
  ├── effects/         # 武器打击特效、相生视觉与 WebAudio 原生音效 (SoundFX)
  ├── entities/        # 英雄、士兵与敌军实体
  ├── render/          # 【展示渲染引擎层】纯水墨表现层解耦
  │   ├── typography/  # 水墨字体栈、DPI 超采样、焦墨高对比度调色板、文字工厂
  │   ├── items/       # 五行金石印章/腰牌、宝石品相游标条、神兵认主腰牌与大招宝匣
  │   ├── figures/     # 武道人体经脉盘坐轮廓、八卦暗纹、演武沙盒木人桩
  │   ├── effects/     # 160px 相生阵脉双色流光墨线、节点光环与水墨视效
  │   └── index.ts     # 展示引擎统一对外导出点
  ├── scenes/          # 主界面、关卡选择、名将录、神兵谱、布阵战斗场景
  ├── types/           # 全局 TypeScript 类型定义
  └── ui/              # 水墨设计系统代理薄层 (InkTheme.ts)、组件与弹窗
  ```

## 🚀 本地开发与运行

### 安装依赖
```bash
npm install
```

### 启动本地开发服务
```bash
npm run dev
# 默认启动于 http://localhost:3000
```

### 运行单元测试
```bash
npm run test
```

### 生产环境打包
```bash
npm run build
```
