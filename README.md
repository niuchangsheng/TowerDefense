# 三国五行塔防 (Three Kingdoms Five Elements TD)

基于 **Phaser 3 + TypeScript + Vite** 构建的水墨国风、肉鸽（Roguelite）五行连锁塔防游戏。

---

## 🌟 核心设计理念

本项目致力于解决传统塔防游戏“固定阵容+纯数值养成导致关卡套路化、后期枯燥刷图”的痛点，创新融合了**幸存者/自走棋三选一锦囊（Augment）**、**五行元素连锁反应（Elemental Reactions）** 与 **百战无尽爬塔（Endless Tower）**：

### 1. 局内外数值解耦（Meta vs In-Run）
* **局外（英雄/装备/星级）保下限**：提供基础攻防底气与流派门票（例如初始锦囊倾向、被动特性槽）。
* **局内（三选一锦囊）定上限**：敌军难度随波次指数级提升，唯有在局内结合出场阵容抓取相生锦囊、引发化学反应，才能实现指数级战力质变！

### 2. 五行元素连锁反应（Elemental Reactions）
告别单一属性克制倍率，引入**元素附着与相生相克化学反应**：
* 💧 **水生木【滋养·蔓延】**：水系使敌人「潮湿」，木系攻击唤出荆棘**定身缠绕 2 秒**，并向周围 90 像素敌人扩散寄生毒素与迟缓。
* 🔥 **木生火【燎原·焚尽】**：敌人处于「寄生」时，火系攻击引爆全屏火海，造成 **240% 范围真实伤害**并留存烈焰灼烧地毯。
* ⛰️ **火生土【熔岩·焦土】**：火系+土系生成熔岩减速陷阱，大幅削减敌军护甲并造成持续百分比灼伤。
* ⚔️ **土生金【淬刃·锋芒】**：土系「破衡」受击硬直后，金系攻击触发穿透飞刃，对周围最多 3 名敌军造成高额暴击弹射。
* ❄️ **金生水【寒芒·碎冰】**：金系破甲后，水系化为极寒将目标**绝对冻结 2.5 秒**，若敌人死亡则引发大范围碎冰爆炸。
* ⚡ **水火相克【汽化·蒸发】**：水与火直接碰撞引发蒸汽爆鸣，瞬间造成 2.2 倍真实暴击伤害！

### 3. 局内天命军师锦囊（三选一海克斯）
* **充能机制**：击杀普通小兵 (+6)、巡防精英 (+25)、波次首领 (+60) 持续积攒令台【军令进度条】；
* **随时暂停运筹**：能量满 100 触发【锦囊就绪】，玩家可随时按 **【空格键】** 或点击令台暂停战局，唤出水墨古风竹简弹窗，从 3 张随机词条中挑选本局核心质变；
* **智能加权卡池**：首批上线 18 张独创锦囊，涵盖五行共鸣（如《借东风》《春风化雨》《生生不息》）、英雄本命进化（关羽《威震华夏》双属性斩击、张飞《当阳怒吼》锥形击退、赵云《七进七出》无双突刺）与全场战阵军策；支持消耗“重整军策”次数刷新。

### 4. 百战奇谋·无尽试炼（Endless Tower）
主菜单设有专属入口，无限波次递增、每 3 波精英巡防、每 5 波首领张角冲阵。供玩家在极限战局中反复验证不同五行锦囊 Build 的构筑上限。

### 5. 水墨宣纸国风美学与零素材技术路线
* 整体界面严格遵循《芥子园画谱》式的纸砚墨韵设计（`InkTheme.ts` 调色板与字体规范）；
* 无需外置大体积贴图，全场景水墨剪影、五行灵魄浮尘与武器打击均采用程序化绘制；
* 音效采用 WebAudio API 现场物理合成（`SoundFX.ts`），兼具轻量、极速加载与原生古意打击感。

## 🛠️ 技术栈与架构

* **游戏引擎**：Phaser 3.70+
* **语言**：TypeScript 5.3+
* **构建工具**：Vite 5.0+
* **测试框架**：Vitest 1.0+
* **代码目录**：
  ```
  src/
  ├── config/          # 游戏、五行、网格与地形常量配置
  ├── core/
  │   ├── augment/     # 军师锦囊能量、抽取与属性管理器
  │   ├── battle/      # 战斗主控制器、伤害计算器、费用与波次
  │   ├── elemental/   # 五行元素反应管理器
  │   ├── enemy/       # 敌军生成与路径追踪
  │   ├── hero/        # 武将战斗、攻击、技能触发
  │   └── level/       # 战役关卡与无尽模式波次生成器
  ├── data/            # 关卡、武将、兵种、敌军与锦囊池静态数据
  ├── effects/         # 武器打击特效、文字特效与 WebAudio 原生音效
  ├── entities/        # 英雄、士兵与水墨敌军实体
  ├── scenes/          # 标题、关卡选择、布阵战斗与结算场景
  ├── types/           # 全局 TypeScript 接口定义
  └── ui/              # 水墨设计系统、军令进度条、锦囊三选一弹窗
  ```

## 🚀 本地开发与运行

### 安装依赖
```bash
npm install
```

### 启动本地开发服务
```bash
npm run dev
# 默认启动于 http://localhost:3000
```

### 运行单元测试
```bash
npm run test
```

### 生产环境打包
```bash
npm run build
```
